## Host validation (before flashing)

- Full target build from the release commit chain; ABI gate passed.
- Audiobook host smoke: scan, multipart indexing, persisted direct resume,
  bookmarks, automatic part advance — green across repeated runs.
- Audiobookshelf host smoke in all five fault modes (default, existing copy,
  local progress, offline restart, conflicts) against the mock server, with
  the sanitizer-instrumented outbox test — green, zero findings.
- Metadata regression suite (156 fixtures) and kernel-log flood tests — green.
- Language completeness: all 24 shipped language files carry the full
  35-key Audiobookshelf block (non-English blocks are English placeholders,
  exactly as the 0.x line shipped them).
- Independent validation (two-agent gate) of the above from a clean checkout.

## Device validation (R1, 2026-10-17)

Installed through the player's own updater (Settings > System > Update
firmware > From SD card). Battery above 30 % throughout.

- Boot: `sonix_launch` + `sonix_player` process tree clean; About shows
  OS 1.3.0, build `171020262008`; kernel `4.4.94-sonix` PREEMPT.
- First-start migration over a card last used by 0.3.0: one audiobook
  rescan, 52 books found; `PRAGMA integrity_check` = ok; schema v4;
  all 10 existing bookmarks and the Audiobookshelf sync link survived.
- Resume: mid-book resume landed on the exact saved position (Beyond Exile,
  884.6 s); pause flushed the new position exactly (916.4 s).
- Audiobookshelf sync against a live server (audiobooks.antonson.co):
  progress upload attempted, zero failures, revision 2 acknowledged; Now
  Playing showed "Audiobookshelf: synced".
- Touch: `hyn_ts` probe clean, no I2C errors in dmesg.
- Memory: player RSS 17.8 MB / 31 threads at idle (leaner than the 0.x
  line on the same device).
- Battery: 100 % reported, charging state clean; open-source modules
  loaded (brcmfmac, x1600_hiby_r1_sound_card, tcs1421_add, soc_efuse,
  sa_earpods_adc).

## Known gaps at release time

- No long-duration playback soak test yet (multi-hour listen).
- Mid-book Wi-Fi drop test against the live server not yet run on hardware
  (covered on the host by the offline-restart smoke mode).
- Audiobookshelf strings are English placeholders in non-English languages,
  matching what 0.x shipped; real translations are welcome.
- Cards upgraded from 0.3.0 may still carry old `.installed.upt`/`.bak`
  markers in the SD root; they are inert (the updater only offers `r1.upt`).
